WorkTools에 이미지를 문자 아트로 바꾸는 ASCII Art Maker를 추가했다. 별도 npm 패키지는 사용하지 않았고, 기존 Jekyll 사이트에 페이지와 스타일, JavaScript를 추가해 구현했다.

### 브라우저에서 이미지 변환하기

이미지 선택과 미리보기에는 브라우저의 File API와 Canvas 2D API를 사용했다. 이미지를 Canvas에 출력한 뒤 픽셀의 밝기를 계산해 어두운 영역에는 밀도 높은 문자를, 밝은 영역에는 공백에 가까운 문자를 배치한다. 이미지 비율을 고려해 문자 아트의 세로 크기를 정하고, 문자 폭·밝기·대비·채도·그레이스케일·반전·문자 세트 설정을 바꾸면 결과를 다시 만든다.

별도의 서버로 이미지를 보내지 않고 브라우저 안에서만 처리하도록 했다.

### 일반 텍스트와 컬러 HTML 복사

일반 텍스트는 그대로 복사할 수 있고, 컬러 결과는 문자마다 픽셀 색상을 인라인 스타일로 지정한 HTML로 만든다. HTML에 들어가는 문자는 엔티티로 이스케이프해 페이지에서 태그로 해석되지 않도록 했다.

복사에는 Clipboard API를 사용한다. 서식 있는 클립보드 복사가 지원되는 브라우저에서는 색상을 포함해 붙여넣을 수 있고, HTML 소스도 따로 확인하고 복사할 수 있다. 클립보드 복사에 실패하면 소스를 선택해 직접 복사할 수 있도록 안내한다.

### 사용한 기술과 테스트

- 별도 외부 패키지 없이 순수 JavaScript로 구현
- 이미지 처리: 브라우저 File API, Canvas 2D API
- 복사: Clipboard API, `ClipboardItem`, `Blob`
- 변환 로직 테스트: Node.js 내장 `node:test`

화면 코드와 변환 로직을 분리하고, 밝기 매핑·색상 출력·HTML 이스케이프·잘못된 입력 처리를 테스트했다.
